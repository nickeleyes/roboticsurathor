# Tic-tac-toe implementation modules

These modules are not a standalone package. They depend on the modified G1 control
loop, policies, environment, robot models, simulator XML, vision checkpoint, and
saved capture data elsewhere in this repository.

Use the complete repository and follow the repository-level
[`TICTACTOE_HANDOFF.md`](../../../../../TICTACTOE_HANDOFF.md) instead of copying this
directory by itself.
